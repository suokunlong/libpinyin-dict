这是适用于 ibus-libpinyin 的词库文件。

Ibus-libpinyin 是 Linux 下使用最广泛的一款拼音输入法。在默认安装配置下，它缺乏一套完善的内置词库，以至于输入一个很常见的词却需要翻好多页才能找到您想要的输入结果。
幸运的是，ibus-libpinyin 有一个导入用户词库的功能，通过导入自定义词库可以极大加速输入体验。

# 词库导入

1. 从这个库的data文件夹中下载需要的词库文件，比如“ChineseCharFreq.txt”（建议全部下载）。  
2. ibus-libpinyin 首选项 > 用户数据 > 导入，在弹出的对话框中选择词库文件然后导入。状态栏若提示“拼音词典已导入”则说明导入成功。

您可以使用 fetch_pinyin.py 脚本为您自己准备的词汇清单自动生成拼音，然后导入。但需要注意的是，自动生成的拼音可能不正确，最典型的错误是它会把“会计 kuai'ji”错误地生成为“会计 hui'ji”。

# 使用

词库导入后，即可开心打字了。
如果遇到词库中仍然没有的词，建议手动加入到下载的词典中，然后再次导入。

# 现有的词库

General.txt: 常用词库汇总
ChineseCharFreq.txt: 现代汉语语料库字频表
ChineseWordsFreq.txt: 现代汉语词频表
Economic.txt: 经济及贸易相关词汇
Finance.txt: 财务会计相关词汇
Legal.txt: 法律相关词汇（律师事务所名称、反倾销及反补贴、民法典等）
Transportation.txt: 交通相关词汇，包括中国的省、自治区、直辖市，省会城市，地级市，县级市（区），北京地铁线路及站点名称等。
